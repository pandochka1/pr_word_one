1. Понятие информации. Данные, информация, знания

Термин информация происходит от латинского informatio — разъяснение, изложение, осведомлённость. В широком смысле информация — это сведения об окружающем мире и протекающих в нём процессах, которые воспринимаются человеком или специальными устройствами.

В сфере информационных систем и программирования информация — это осмысленные данные, представленные в форме, пригодной для передачи, обработки и хранения. Различают три взаимосвязанных понятия:

Данные (Data)Совокупность зафиксированных сигналов, символов или чисел, не имеющих смысла вне контекста. Пример: число «404» — это данные; это может быть HTTP-статус (Not Found), номер аудитории или цена товара.
Информация (Information)Данные, помещённые в контекст и наделённые смыслом. Пример: «Сервер вернул HTTP-код 404 (Not Found), значит, запрашиваемая страница не существует».
Знания (Knowledge)Структурированная информация, проверенная практикой и пригодная для принятия решений. Пример: «Если при запросе к API возвращается 404, необходимо проверить правильность URL в коде».
Информация (в контексте АИС) Это совокупность данных, обработанных и организованных так, чтобы они могли быть использованы для анализа, принятия решений и управления. В АИС информация хранится в базах данных (БД), обрабатывается серверными приложениями и предоставляется пользователю через интерфейс (API, веб-интерфейс или десктопное приложение).
Пример для разработчика ПО: когда пользователь вводит логин и пароль в форму аутентификации, эти символы — данные. После проверки на соответствие записи в БД система возвращает сообщение «Вход выполнен» — это информация. А правило «Пароль должен содержать не менее 8 символов, включая цифры и буквы разного регистра» — это знание, заложенное в бизнес-логику приложения.

2. Способы восприятия и хранения информации

Способы восприятия

Для специалиста в области ИС важно понимать, что информация может существовать в различных формах:

  • Визуальная — текст, изображения, видео, интерфейсы. Основы UI/UX.
  • Аудиальная — звук, речь. ASR, IVR.
  • Тактильная — осязание. Haptic feedback, сенсорные экраны.
  • Цифровая (машинная) — двоичный код. Любая информация преобразуется в двоичный код для обработки процессором.

Способы хранения

Энергозависимая память. В современных АИС рекомендуется от 16 ГБ RAM для серверов приложений.

Пример: при запуске IDE (VS Code, IntelliJ IDEA) её код загружается из SSD в RAM.

SSD — твердотельный накопитель. HDD — жёсткий диск.

Пример: СУБД PostgreSQL хранит таблицы на SSD для быстрых операций.

Данные на удалённых серверах (Yandex Object Storage, AWS S3).

Пример: файлы статики (CSS, JS, изображения) размещаются в объектном хранилище.

3. Информационные технологии (ИТ): понятие, классификация, задачи

ИТ (IT — Information Technology, информационные технологии) Совокупность методов, процессов и программно-технических средств для сбора, обработки, хранения, передачи и представления информации с целью снижения трудоёмкости и повышения эффективности.

Классификация ИТ

ПризнакВиды ИТПримеры
По типу информацииТекстовые, табличные, графические, мультимедийныеNLP, Computer Vision, DSP
По степени автоматизацииРучные, автоматизированные, автоматическиеCI/CD, автотесты
По сфере примененияОфисные, промышленные, образовательныеERP, CRM, LMS
По архитектуреДесктопные, веб, мобильные, облачныеSPA на React, Flutter, Spring Boot

Основные задачи ИТ в АИС

Сбор данныхИз веб-форм, API, IoT-датчиков. Парсеры, веб-хуки, Kafka.
Обработка данныхВалидация, фильтрация, агрегация. Java, Python, C#, SQL, ETL.
Хранение данныхСУБД: PostgreSQL, MySQL, MongoDB, Redis.
Передача данныхHTTP/HTTPS, gRPC, WebSocket, REST/SOAP API.
ПредставлениеUI: HTML/CSS/JS, WPF, Qt, Electron, Grafana.
Защита информацииAES, RSA, JWT, OAuth 2.0, антивирусы, бэкапы.

4. Основные устройства ввода и вывода

Устройства ввода-вывода (I/O) обеспечивают взаимодействие пользователя с АИС. Драйверы преобразуют физические сигналы в цифровые данные и обратно.

КлавиатураВвод текста, команд ОС, заполнение форм.
Мышь / ТачпадУправление курсором. Ключевое для IDE и администрирования.
МикрофонВвод звука. Голосовые интерфейсы, ASR, видеоконференции.
Веб-камераВвод видео. Видеозвонки, биометрия, QR-сканеры.
СканерПреобразование бумажных документов. OCR.
Сенсорный экранВвод касанием. POS-терминалы, киоски, мобильные приложения.
МониторВизуальное отображение. Разрешение 2K/4K, цветовой охват.
ПринтерВывод на бумагу. Печать отчётов, накладных, актов.
Колонки / НаушникиВывод звука. Мультимедийные АИС, голосовые помощники.
ПроекторПроецирование. Демонстрация ПО, презентации.
Для разработчика: веб-приложения — responsive design. Десктопные — горячие клавиши, печать, WebRTC для аудио/видео.

5. Современные smart-устройства

Smart-устройство (Smart Device) Устройство с процессором, памятью, датчиками и сетевым подключением, способное собирать данные, обрабатывать их и выполнять действия.

Smart-устройства объединяют функции ввода, вывода и обработки. Программирование таких устройств — направление IoT.

СмартфонПлатформа для iOS/Android. GPS, акселерометр, гироскоп.
Смарт-часыwatchOS, Wear OS. Push-уведомления через API.
Умная колонкаАлиса, Салют. Разработка навыков через Yandex Dialogs API.
IoT-устройстваЛампы, розетки, термостаты. Протоколы MQTT, CoAP.
Smart-TVTizen, webOS, Android TV. Digital signage.
POS-терминалыПриём оплаты. Интеграция через API эквайеров. PCI DSS.
Пример интеграции: система «Умный склад» (WMS) использует IoT-датчики, smart-весы, ТСД на Android. Данные через MQTT в АИС, уведомления через Telegram API.
